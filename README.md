Airborne Quick Sneak
A lightweight client-side NeoForge mod that gives you precise control over sneaking and movement speed while airborne.

Overview
Airborne Quick Sneak (AQS) enhances your aerial mobility by letting you toggle sneak posture and cycle through four distinct speed modes — all from the air, with a single hotkey. The mod is designed to be completely unobtrusive: it stays dormant while you're on the ground and only activates when you're actually airborne. Once you land, everything resets to vanilla behavior.

Built for NeoForge 1.21.1, fully client-side, and safe for use on any server that allows client-side mods.

Features
🪂 Airborne Sneak
While airborne, press Alt + Space (rebindable) to force the player into a sneaking state. This shrinks your hitbox from 1.8 blocks to 1.5 blocks, allowing you to slip into tight spaces such as under stairs or through low gaps — places you normally couldn't enter while jumping or falling.

A HUD indicator in the top-left corner displays "Airborne Sneaking" whenever the state is active.
Sneaking is automatically disabled the moment you touch the ground.
🏃 Speed Mode Cycling
Press Alt + Backspace (rebindable) while airborne to cycle through four movement speeds:

Mode	HUD Indicator
Flying Speed	Flying Speed
Flying Sprint	Flying Sprint
Walking Speed	Walking Speed
Walking Sprint	Walking Sprint
The active mode is shown in the top-left corner of the screen. Each press advances to the next mode in the cycle.

⚙️ In-Game Settings
Press `Alt + `` (rebindable) to open the settings screen, which provides:

Mod toggle — enable or disable the entire mod without leaving the game
Airborne Sneak toggle — same as pressing Alt + Space
Speed Mode toggle — same as pressing Alt + Backspace

Design Philosophy
Zero impact on the ground. Everything resets the moment you land.
Client-side only. No server installation required.
Non-invasive. Uses Mixin only where necessary (hitbox adjustment and sneak-state enforcement).
Respects vanilla. No changes to block placement, entity interaction, or other core mechanics beyond what's needed.
